#  Hand Cricket

A console-based Hand Cricket game built with Python where the player competes against the computer.

The game includes a toss, batting and bowling choices, score tracking, and target chasing.

## Features

*  Toss system
*  Player batting and bowling
* Computer opponent
*  Score tracking
*  Target chase
*  Winner detection
*  Input validation

## How the Game Works

1. The player chooses Heads or Tails for the toss.
2. The toss determines who gets to choose batting or bowling.
3. The player and computer select numbers from 1–6.
4. If both choose the same number, the batsman is out.
5. Otherwise, the selected number is added to the batting team's score.
6. The second innings continues until the target is chased or the batsman is dismissed.

## Requirements

* Python 3.x

## How to Run

Clone the repository and run:

```bash
python hand_cricket.py
```
