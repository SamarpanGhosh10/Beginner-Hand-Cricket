# 🏏 Beginner Hand Cricket

A simple console-based Hand Cricket game built using Python.

 -->Features

- Toss system (Head/Tail)
- Player vs Computer
- Batting and Bowling modes
- Score tracking
- Target chase system
- Winner announcement

--> How to Run

1. Install Python 3.x
2. Clone this repository
3. Run:

```bash
python hand_cricket.py
